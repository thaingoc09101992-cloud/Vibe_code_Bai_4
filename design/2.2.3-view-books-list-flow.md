# 2.2.3 Xem Danh Sách Sách - Flowchart

## Mô tả
Tính năng xem danh sách sách với tìm kiếm, lọc, sắp xếp và phân trang.

**Actor:** Tất cả người dùng (không cần login)  
**Phụ thuộc:** Không

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Người dùng truy cập trang danh sách sách]) --> LoadBooks[Tải danh sách sách]
    LoadBooks --> DisplayBooks[Hiển thị danh sách:<br/>- Tên sách<br/>- Tác giả<br/>- Năm xuất bản<br/>- Thể loại<br/>- Số lượng có sẵn<br/>- Số lượng đang mượn]
    DisplayBooks --> Pagination[Phân trang:<br/>10 sách/trang]
    Pagination --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Tìm Kiếm

```mermaid
flowchart TD
    Start([Người dùng nhập từ khóa tìm kiếm]) --> InputKeyword[Nhập từ khóa:<br/>tên sách hoặc tác giả]
    InputKeyword --> Search{Thực hiện tìm kiếm}
    Search --> CheckResults{Có kết quả?}
    
    CheckResults -->|Có| DisplayResults[Hiển thị kết quả tìm kiếm]
    CheckResults -->|Không| DisplayNoResults[Hiển thị thông báo:<br/>Không tìm thấy sách]
    
    DisplayResults --> Pagination[Phân trang kết quả]
    DisplayNoResults --> End([Kết thúc])
    Pagination --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style DisplayNoResults fill:#fff9c4
```

## Flowchart - Lọc Theo Thể Loại

```mermaid
flowchart TD
    Start([Người dùng chọn thể loại từ dropdown]) --> SelectCategory[Chọn thể loại]
    SelectCategory --> Filter[Lọc sách theo thể loại]
    Filter --> CheckResults{Có sách trong<br/>thể loại này?}
    
    CheckResults -->|Có| DisplayFiltered[Hiển thị danh sách<br/>sách đã lọc]
    CheckResults -->|Không| DisplayEmpty[Hiển thị thông báo:<br/>Không có sách trong thể loại này]
    
    DisplayFiltered --> Pagination[Phân trang]
    DisplayEmpty --> End([Kết thúc])
    Pagination --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style DisplayEmpty fill:#fff9c4
```

## Flowchart - Sắp Xếp

```mermaid
flowchart TD
    Start([Người dùng chọn tiêu chí sắp xếp]) --> SelectSort[Chọn tiêu chí:<br/>- Tên A-Z<br/>- Năm xuất bản Mới nhất<br/>- Lượt mượn Phổ biến nhất]
    SelectSort --> Sort[Thực hiện sắp xếp]
    Sort --> DisplaySorted[Hiển thị danh sách<br/>đã sắp xếp]
    DisplaySorted --> Pagination[Phân trang]
    Pagination --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Phân Trang

```mermaid
flowchart TD
    Start([Người dùng click số trang hoặc Next/Prev]) --> Navigate[Điều hướng đến trang]
    Navigate --> LoadPage[Tải dữ liệu trang mới]
    LoadPage --> DisplayPage[Hiển thị 10 sách của trang]
    DisplayPage --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Chức năng

- **Tìm kiếm:** Theo tên sách hoặc tác giả
- **Lọc:** Theo thể loại
- **Sắp xếp:** 
  - Tên (A-Z)
  - Năm xuất bản (Mới nhất)
  - Lượt mượn (Phổ biến nhất)
- **Phân trang:** 10 sách trên 1 trang

## Luồng thay thế

1. **Không có kết quả tìm kiếm:** Hiển thị thông báo "Không tìm thấy sách"
2. **Không có sách trong thể loại:** Hiển thị thông báo "Không có sách trong thể loại này"

## Edge Cases

- Không có kết quả tìm kiếm
- Không có sách trong thể loại đã chọn
- Danh sách sách rỗng
- Kết hợp tìm kiếm + lọc + sắp xếp
