# 2.2.1 Quản lý Thể Loại Sách - Flowchart

## Mô tả
Tính năng quản lý thể loại sách: xem, thêm, sửa, xóa thể loại.

**Actor:** Nhân viên thư viện  
**Phụ thuộc:** 2.1.2 (Cần đăng nhập với vai trò nhân viên)

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Nhân viên truy cập trang quản lý thể loại]) --> CheckAuth{Đã đăng nhập<br/>với vai trò nhân viên?}
    CheckAuth -->|Chưa| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    CheckAuth -->|Đã đăng nhập| LoadCategories[Tải danh sách thể loại]
    LoadCategories --> DisplayTable[Hiển thị danh sách<br/>dạng bảng có thể sửa trực tiếp]
    DisplayTable --> End([Kết thúc])
    RedirectLogin --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style RedirectLogin fill:#fff9c4
```

## Flowchart - Thêm Thể Loại

```mermaid
flowchart TD
    Start([Nhân viên click Thêm thể loại sách]) --> ShowForm[Hiển thị form thêm thể loại]
    ShowForm --> InputName[Nhập tên thể loại]
    InputName --> Validate{Validate dữ liệu}
    
    Validate -->|Tên trống| ErrorEmpty[Hiển thị lỗi:<br/>Tên thể loại không được để trống]
    Validate -->|Tên > 50 ký tự| ErrorTooLong[Hiển thị lỗi:<br/>Tên thể loại tối đa 50 ký tự]
    Validate -->|Tên đã tồn tại| ErrorExists[Hiển thị lỗi:<br/>Tên thể loại đã tồn tại]
    
    ErrorEmpty --> InputName
    ErrorTooLong --> InputName
    ErrorExists --> InputName
    
    Validate -->|Hợp lệ| SaveCategory[Lưu thể loại mới]
    SaveCategory --> Success[Hiển thị thông báo:<br/>Thêm thể loại thành công]
    Success --> RefreshList[Làm mới danh sách]
    RefreshList --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorEmpty fill:#ffcdd2
    style ErrorTooLong fill:#ffcdd2
    style ErrorExists fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Xóa Thể Loại

```mermaid
flowchart TD
    Start([Nhân viên click Xóa trên bảng]) --> CheckBooks{Có sách nào<br/>thuộc thể loại này?}
    CheckBooks -->|Có| ErrorHasBooks[Hiển thị thông báo:<br/>Không thể xóa thể loại<br/>đang được sử dụng]
    CheckBooks -->|Không| ConfirmDelete[Hiển thị xác nhận xóa]
    
    ErrorHasBooks --> End([Kết thúc])
    
    ConfirmDelete --> UserConfirm{Người dùng<br/>xác nhận?}
    UserConfirm -->|Hủy| Cancel[Hủy thao tác]
    UserConfirm -->|Xác nhận| DeleteCategory[Xóa thể loại]
    
    Cancel --> End
    DeleteCategory --> Success[Hiển thị thông báo:<br/>Xóa thể loại thành công]
    Success --> RefreshList[Làm mới danh sách]
    RefreshList --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorHasBooks fill:#ffcdd2
    style Cancel fill:#fff9c4
    style Success fill:#c8e6c9
```

## Validation Rules

- **Tên thể loại:** Không được để trống, tối đa 50 ký tự

## Luồng thay thế

1. **Có sách thuộc thể loại:** Không cho phép xóa, hiển thị thông báo
2. **Tên thể loại đã tồn tại:** Hiển thị lỗi và yêu cầu nhập tên khác

## Edge Cases

- Tên thể loại trống
- Tên thể loại quá dài (>50 ký tự)
- Xóa thể loại đang được sử dụng
- Tên thể loại trùng với thể loại khác
