# 2.7.1 Báo Cáo Tổng Quan - Dashboard - Flowchart

## Mô tả
Tính năng hiển thị dashboard với các thống kê tổng quan.

**Actor:** Quản lý viên, Nhân viên thư viện  
**Phụ thuộc:** 2.1.2, 2.2.2, 2.3.1, 2.4.2 (Cần có dữ liệu sách, mượn, trả)

## Flowchart

```mermaid
flowchart TD
    Start([Đăng nhập với vai trò Quản lý viên hoặc Nhân viên]) --> CheckAuth{Đã đăng nhập<br/>với vai trò hợp lệ?}
    CheckAuth -->|Chưa| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    CheckAuth -->|Đã đăng nhập| AccessDashboard[Truy cập Dashboard]
    
    RedirectLogin --> End([Kết thúc])
    
    AccessDashboard --> LoadStatistics[Tải dữ liệu thống kê]
    LoadStatistics --> CheckData{Có dữ liệu?}
    
    CheckData -->|Không| DisplayEmpty[Hiển thị 0 hoặc<br/>Chưa có dữ liệu]
    CheckData -->|Có| CalculateStats[Tính toán thống kê]
    
    DisplayEmpty --> End
    
    CalculateStats --> DisplayBooks[Hiển thị Tổng số sách:<br/>- Có sẵn<br/>- Đang mượn<br/>- Bị mất<br/>- Hư hỏng]
    
    CalculateStats --> DisplayReaders[Hiển thị Tổng số độc giả:<br/>- Hoạt động<br/>- Vô hiệu hóa]
    
    CalculateStats --> DisplayTodayBorrows[Hiển thị Tổng đơn mượn hôm nay]
    
    CalculateStats --> DisplayTopBooks[Hiển thị Top 5 sách phổ biến nhất]
    
    CalculateStats --> DisplayOverdue[Hiển thị Danh sách độc giả<br/>nợ quá hạn]
    
    DisplayBooks --> End
    DisplayReaders --> End
    DisplayTodayBorrows --> End
    DisplayTopBooks --> End
    DisplayOverdue --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style RedirectLogin fill:#fff9c4
    style DisplayEmpty fill:#fff9c4
```

## Thông tin hiển thị

- **Tổng số sách:** Có sẵn / Đang mượn / Bị mất / Hư hỏng
- **Tổng số độc giả:** Hoạt động / Vô hiệu hóa
- **Tổng đơn mượn hôm nay**
- **Top 5 sách phổ biến nhất**
- **Danh sách độc giả nợ quá hạn**

## Luồng thay thế

1. **Không có dữ liệu:** Hiển thị 0 hoặc "Chưa có dữ liệu"

## Edge Cases

- Không có dữ liệu để hiển thị
- Lỗi khi tính toán thống kê
- Không có quyền truy cập (không phải quản lý viên hoặc nhân viên)
