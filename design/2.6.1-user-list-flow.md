# 2.6.1 Danh Sách Người Dùng - Flowchart

## Mô tả
Tính năng quản lý viên xem danh sách người dùng, tìm kiếm, lọc và vô hiệu hóa/kích hoạt tài khoản.

**Actor:** Quản lý viên  
**Phụ thuộc:** 2.1.2 (Cần đăng nhập với vai trò quản lý viên)

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Quản lý viên truy cập trang Quản lý người dùng]) --> CheckAuth{Đã đăng nhập<br/>với vai trò quản lý viên?}
    CheckAuth -->|Chưa| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    CheckAuth -->|Đã đăng nhập| LoadUsers[Tải danh sách người dùng]
    
    RedirectLogin --> End([Kết thúc])
    
    LoadUsers --> DisplayList[Hiển thị danh sách:<br/>- Email, Tên<br/>- Vai trò Reader/Librarian/Admin<br/>- Ngày tham gia<br/>- Trạng thái Kích hoạt/Vô hiệu hóa]
    DisplayList --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style RedirectLogin fill:#fff9c4
```

## Flowchart - Tìm Kiếm

```mermaid
flowchart TD
    Start([Quản lý viên nhập từ khóa tìm kiếm]) --> InputKeyword[Nhập từ khóa:<br/>email hoặc tên]
    InputKeyword --> Search[Thực hiện tìm kiếm]
    Search --> CheckResults{Có kết quả?}
    
    CheckResults -->|Có| DisplayResults[Hiển thị kết quả tìm kiếm]
    CheckResults -->|Không| DisplayNoResults[Hiển thị thông báo:<br/>Không tìm thấy người dùng]
    
    DisplayResults --> End([Kết thúc])
    DisplayNoResults --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style DisplayNoResults fill:#fff9c4
```

## Flowchart - Lọc Theo Vai Trò

```mermaid
flowchart TD
    Start([Quản lý viên chọn vai trò từ dropdown]) --> SelectRole[Chọn vai trò:<br/>- Reader<br/>- Librarian<br/>- Admin]
    SelectRole --> Filter[Lọc người dùng theo vai trò]
    Filter --> DisplayFiltered[Hiển thị danh sách đã lọc]
    DisplayFiltered --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Vô Hiệu Hóa/Kích Hoạt

```mermaid
flowchart TD
    Start([Quản lý viên click Vô hiệu hóa/Kích hoạt]) --> CheckCurrentStatus{Trạng thái hiện tại?}
    CheckCurrentStatus -->|Kích hoạt| ConfirmDisable[Hiển thị xác nhận vô hiệu hóa]
    CheckCurrentStatus -->|Vô hiệu hóa| ConfirmEnable[Hiển thị xác nhận kích hoạt]
    
    ConfirmDisable --> UserConfirm{Người dùng<br/>xác nhận?}
    ConfirmEnable --> UserConfirm
    
    UserConfirm -->|Hủy| Cancel[Hủy thao tác]
    UserConfirm -->|Xác nhận| UpdateStatus[Cập nhật trạng thái tài khoản]
    
    Cancel --> End([Kết thúc])
    
    UpdateStatus --> Success[Hiển thị thông báo:<br/>Cập nhật trạng thái thành công]
    Success --> RefreshList[Làm mới danh sách]
    RefreshList --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style Cancel fill:#fff9c4
    style Success fill:#c8e6c9
```

## Luồng thay thế

1. **Không tìm thấy người dùng:** Hiển thị "Không tìm thấy người dùng"

## Edge Cases

- Không tìm thấy người dùng
- Vô hiệu hóa tài khoản của chính mình (có thể không cho phép)
- Tài khoản không tồn tại
