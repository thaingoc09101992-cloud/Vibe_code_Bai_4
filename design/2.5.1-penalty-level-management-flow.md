# 2.5.1 Quản lý Mức Phạt - Flowchart

## Mô tả
Tính năng quản lý viên quản lý các mức phạt trong hệ thống: xem, thêm, sửa, xóa mức phạt.

**Actor:** Quản lý viên  
**Phụ thuộc:** 2.1.2 (Cần đăng nhập với vai trò quản lý viên)

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Quản lý viên truy cập trang quản lý mức phạt]) --> CheckAuth{Đã đăng nhập<br/>với vai trò quản lý viên?}
    CheckAuth -->|Chưa| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    CheckAuth -->|Đã đăng nhập| LoadPenalties[Tải danh sách mức phạt]
    
    RedirectLogin --> End([Kết thúc])
    
    LoadPenalties --> DisplayTable[Hiển thị danh sách dạng bảng<br/>có thể sửa trực tiếp:<br/>- Tên mức phạt<br/>- Số tiền<br/>- Ngày phạt]
    DisplayTable --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style RedirectLogin fill:#fff9c4
```

## Flowchart - Thêm Mức Phạt

```mermaid
flowchart TD
    Start([Quản lý viên click Thêm mức phạt]) --> ShowForm[Hiển thị form thêm mức phạt]
    ShowForm --> InputData[Nhập thông tin:<br/>- Tên mức phạt<br/>- Số tiền<br/>- Ngày phạt<br/>mặc định: ngày hiện tại]
    InputData --> Validate{Validate dữ liệu}
    
    Validate -->|Tên mức phạt trống| ErrorNameEmpty[Hiển thị lỗi:<br/>Tên mức phạt không được để trống]
    Validate -->|Tên mức phạt > 25 ký tự| ErrorNameLong[Hiển thị lỗi:<br/>Tên mức phạt tối đa 25 ký tự]
    Validate -->|Số tiền <= 0| ErrorAmount[Hiển thị lỗi:<br/>Số tiền phải > 0]
    Validate -->|Số tiền không phải số| ErrorAmountInvalid[Hiển thị lỗi:<br/>Số tiền không hợp lệ]
    Validate -->|Ngày phạt không hợp lệ| ErrorDate[Hiển thị lỗi:<br/>Ngày phạt không hợp lệ]
    
    ErrorNameEmpty --> InputData
    ErrorNameLong --> InputData
    ErrorAmount --> InputData
    ErrorAmountInvalid --> InputData
    ErrorDate --> InputData
    
    Validate -->|Tất cả hợp lệ| SavePenalty[Lưu mức phạt mới]
    SavePenalty --> Success[Hiển thị thông báo:<br/>Thêm mức phạt thành công]
    Success --> RefreshList[Làm mới danh sách]
    RefreshList --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorNameEmpty fill:#ffcdd2
    style ErrorNameLong fill:#ffcdd2
    style ErrorAmount fill:#ffcdd2
    style ErrorAmountInvalid fill:#ffcdd2
    style ErrorDate fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Sửa Mức Phạt

```mermaid
flowchart TD
    Start([Quản lý viên sửa trực tiếp trên bảng]) --> EditCell[Sửa thông tin mức phạt trong ô bảng]
    EditCell --> Validate{Validate dữ liệu}
    
    Validate -->|Có lỗi validation| ShowErrors[Hiển thị lỗi cụ thể<br/>cho từng trường]
    Validate -->|Hợp lệ| SaveChanges[Lưu thay đổi]
    
    ShowErrors --> EditCell
    
    SaveChanges --> Success[Hiển thị thông báo:<br/>Cập nhật mức phạt thành công]
    Success --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ShowErrors fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Xóa Mức Phạt

```mermaid
flowchart TD
    Start([Quản lý viên click Xóa trên bảng]) --> ConfirmDelete[Hiển thị xác nhận xóa]
    ConfirmDelete --> UserConfirm{Người dùng<br/>xác nhận?}
    UserConfirm -->|Hủy| Cancel[Hủy thao tác]
    UserConfirm -->|Xác nhận| DeletePenalty[Xóa mức phạt]
    
    Cancel --> End([Kết thúc])
    
    DeletePenalty --> Success[Hiển thị thông báo:<br/>Xóa mức phạt thành công]
    Success --> RefreshList[Làm mới danh sách]
    RefreshList --> End
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style Cancel fill:#fff9c4
    style Success fill:#c8e6c9
```

## Validation Rules

- **Tên mức phạt:** Không được để trống, tối đa 25 ký tự
- **Số tiền:** Phải > 0, kiểu số
- **Ngày phạt:** Ngày hợp lệ (mặc định là ngày hiện tại)

## Luồng thay thế

1. **Validation lỗi:** Hiển thị lỗi cụ thể cho từng trường không hợp lệ

## Edge Cases

- Tên mức phạt trống hoặc quá dài (>25 ký tự)
- Số tiền <= 0 hoặc không phải số
- Ngày phạt không hợp lệ
- Mức phạt đang được sử dụng (có thể cần kiểm tra trước khi xóa)
